# 更新记录

版本号与 `tauri.conf.json` 一致；每个版本对应一个 `desktop-v<版本>` 的 Release。

## 0.2.1

**修复**
- Windows：迷你窗、悬浮拖拽窗带着无法点击的原生标题栏、空白地出现在屏幕左上角。无边框小窗不再使用带阴影的无边框模式（这种模式下系统会在窗口上画出原生标题栏），显示后再去掉标题栏样式并重新定位；小窗不该出现时（启动时、悬浮窗关闭时）会被自动收起
- 补上 Windows ARM64 安装包和便携版（0.2.0 的发布流程漏装了 ARM64 编译目标，这两个文件没有生成）

## 0.2.0

在 0.1.1 的基础上补充了媒体库、媒体工具、AI、自动化、网络、安全与隐私、桌面体验几组功能。每组的详细说明见 `docs/` 下的对应文档。

**媒体库与整理**（[说明](../docs/library-and-tools.md)）
- 标签、收藏、评分、备注；导入已有文件夹；磁盘统计；回收站；按规则整理文件夹
- 重复文件检测（内容哈希 + 画面相似）；字幕全文搜索；预览图与镜头拆分；导出 CSV / JSON；备份与还原

**后处理与媒体工具**（[说明](../docs/library-and-tools.md)）
- 工具箱：压缩、GIF、竖转横、倍速、响度、旋转、转封装、截图、拼接、裁剪、去音轨、音频标签
- 字幕工具（平移、校准、双语合并、格式互转、弹幕 XML 转 ASS）；弹幕样式
- 设置大小上限后自动选不超过上限的最高清晰度；下载失败时自动降一档重下

**AI**（[说明](../docs/library-and-tools.md)）
- 语音转文字（在线接口或本机 whisper.cpp）、字幕翻译、摘要与章节、把章节写进视频；接口密钥加密保存

**自动化与集成**（[说明](../docs/automation.md)）
- 推送通知（Telegram、Bark、Server酱、企业微信、钉钉、飞书、ntfy、Webhook）
- 下载完成后自动上传（WebDAV 或复制到另一个文件夹）、自动规则、自定义站点规则
- 播客 / RSS 订阅、直播预约录制、订阅保留策略
- HTTP 接口 v1、局域网网页控制台、命令行（`clearclip add / list / status / pause / resume / cancel / remove / search`）
- 浏览器扩展 1.2：嗅探页面里的视频流和视频文件，一键发送

**网络与稳定性**
- 限速计划（按星期和时段）、省流量模式、线路测速

**安全与隐私**（[说明](../docs/security-and-privacy.md)）
- 应用锁（启动即锁、空闲自动锁、老板键）、隐私模式、加密保险箱（Argon2id + 分块 AES-256-GCM）、一键清除

**桌面体验**（[说明](../docs/desktop-experience.md)）
- 首次引导、命令面板（Ctrl+K）、任务详情、内置播放器（支持字幕）、悬浮拖拽窗、托盘显示总速度
- 英文界面（设置 → 通用 → 语言）

**安装包**
- macOS 改为一个同时支持 Apple 芯片和 Intel 的通用安装包（`_universal.dmg`）
- 新增 Windows ARM64 安装包和便携版（实验性）

**已知限制**
- 英文界面是机器翻译，后端返回的错误消息等动态文字仍是中文
- 内置播放器能否播放 H.264 取决于系统自带的解码器
- 安装包没有代码签名（macOS 为临时签名），首次运行说明见 Release 页面
